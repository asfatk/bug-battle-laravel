\# BUG BATTLE — LARAVEL



Repository ini berisi penyelesaian tiga kasus Bug Battle menggunakan framework Laravel.



\## Daftar Kasus



\### 1. Kasus 01 — CRUD Buku

Memperbaiki fitur pengelolaan data buku, meliputi:

\- Menampilkan daftar buku.

\- Menambahkan buku.

\- Menghapus buku.



Folder: `Kasus\_01\_CRUD\_Buku`



\### 2. Kasus 02 — Relasi Buku dan Kategori

Memperbaiki relasi One-to-Many antara kategori dan buku menggunakan Eloquent Relationship.



Perbaikan meliputi:

\- Relasi Category hasMany Book.

\- Relasi Book belongsTo Category.

\- Foreign key category\_id.

\- Eager loading kategori.

\- Menampilkan nama kategori pada halaman buku.



Folder: `Kasus\_02\_Relasi\_Kategori`



\### 3. Kasus 03 — Pencarian dan Filter Buku

Memperbaiki fitur pencarian dan filter buku.



Perbaikan meliputi:

\- Pencarian berdasarkan judul dan penulis.

\- Pencarian parsial menggunakan LIKE.

\- Filter berdasarkan kategori.

\- Penggabungan pencarian dan filter.

\- Menampilkan pesan ketika hasil pencarian kosong.

\- Mempertahankan nilai pencarian setelah submit.



Folder: `Kasus\_03\_Search\_Filter`



\## Teknologi

\- PHP

\- Laravel

\- MySQL

\- Blade

\- Eloquent ORM



\## Bukti Pengerjaan



Bukti screenshot masing-masing kasus tersedia di folder `BUKTI\_SCREENSHOT`.



\## Catatan

Setiap kasus merupakan project Laravel yang berdiri sendiri dan memiliki konfigurasi database masing-masing.
